# MCP-Powered Multi-Agent AI Automation Platform

A supervisor-based multi-agent AI automation platform built using LangGraph, LangChain, MCP, FastAPI and Groq.

## Technology Stack

- Python
- LangGraph
- LangChain
- Model Context Protocol (MCP)
- FastMCP
- Groq
- FastAPI
- PostgreSQL
- Redis
- Docker

?? Initial project setup completed. Development in progress.

## Planned Features

- Supervisor-based multi-agent orchestration
- Research, Analysis and Execution agents
- Dynamic MCP tool discovery
- Custom MCP servers
- Human-in-the-loop approval
- Shared state and conversational memory
- PostgreSQL and Redis integration
